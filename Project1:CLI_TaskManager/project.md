# Project 1: CLI Task Manager

This document explains what Project 1 does in simple terms.

## What does this project do?
This project is a Command Line Task Manager. It lets you type commands to manage a to-do list. 

It can do four things:
1. Add Tasks: Type in new tasks.
2. View Tasks: Print a list of your tasks.
3. Complete Tasks: Mark a task as done.
4. Save Data: Your tasks are saved to a file, so they are there the next time you open the program.

## How does the code work?
Here is a simple way to think about the different parts of the code:
* The Boss: You, the person typing commands.
* The Assistant (TaskManager): The Python code that follows your orders.
* The Clipboard (tasks.json): The file where the assistant saves your tasks.
* The Highlighters (colorama): A tool the assistant uses to print text in different colors.
* The Intercom (while True loop): The menu that stays on the screen, waiting for your next command.
